<b>Web Application Mimicking Google Sheets<b> <br>
Overview
This web application is designed to closely mimic the user interface and core functionalities of Google Sheets. It allows users to perform data entry, apply mathematical and data quality functions, format cells, and interact with a spreadsheet-like interface. The focus is on accurate functionality for handling formulas, cell dependencies, and basic data validation.

Features
1. Spreadsheet Interface
Google Sheets UI Mimicry: The application closely resembles Google Sheets with a similar layout, including the toolbar, formula bar, and grid of cells.
Drag Functionality: Users can drag cell content, formulas, and selections in the same manner as Google Sheets.
Cell Dependencies: Formulas automatically update when changes are made to dependent cells.
Cell Formatting: Users can apply basic formatting such as bold, italics, font size, and color.
Row/Column Management: Users can add, delete, and resize rows and columns.

Code Quality and Maintainability
The code follows modular principles, separating concerns such as UI, formula evaluation, and data manipulation.
Functions are well-tested with unit tests (if applicable) and maintainable to accommodate potential future enhancements.

Conclusion
This project mimics the functionality and UI of Google Sheets with core features like mathematical and data quality functions, cell management, and formatting. It’s built with modularity and scalability in mind, providing a platform for further feature development.
